# 🎓 Student Grade Manager in C

### Final Project | Code & AI with Bilal

Welcome to the final project of our **C Programming Fundamentals** course!

This project demonstrates how to build a Student Grade Manager using C programming. It combines several important programming concepts into one practical application.

## 💻 About the Project

The Student Grade Manager is a console application that allows users to:

- Enter names and grades for 3 students
- Validate grades between 0 and 100
- Calculate the class average
- Identify the student with the highest grade
- Save student results to a text file

## 📚 Programming Concepts Used

- Variables and data types
- Arrays and structures
- Functions and parameters
- Loops and conditional statements
- Pointers
- User input validation
- File handling

## 📂 Project Files

**Episode20_Student_Grade_Manager.c**

The complete C source code.

**grade_report.txt**

Automatically generated when the program runs successfully.

## 🚀 How to Run the Project

**Step 1: Install a C compiler**

Make sure GCC is installed on your computer.

**Step 2: Download the source code**

Download the C file from this repository.

**Step 3: Compile the program**

```bash
gcc Episode20_Student_Grade_Manager.c -o grade_manager
```

**Step 4: Run the program**

On Windows:

```bash
grade_manager.exe
```

On Linux or macOS:

```bash
./grade_manager
```
